# 🌿 心语星途 (XinYu) —— 你的科研流程好搭子

> \*\*“它不教我们怎么做科研，它帮我们看见自己是如何做科研的。”\*\*



## 📖 项目缘起

在语言学与人文实证研究中，我们太容易被外部的指标（论文、DDL、导师的催促）裹挟，却忘了停下来审视自己的“内在齿轮”是如何咬合的。
面对浩如烟海的文献、繁杂的语料清洗、以及令人头秃的 IPA 乱码，科研往往变成了一场孤独的消耗战。

**心语星途 (XinYu)** 不是一个居高临下的“监工”，也不是一个堆砌 AI 工具的“导航站”。它是一个**科研效能与心智成长的个人量化追踪系统**。
它致力于帮你记录时间、捕获情绪、沉淀避坑指南，让你在经历一次次开题、结项后，能积累出一种 **“老艺术家的优雅与从容”**。

\---

## ✨ 核心产品哲学

1. **⏳ 无终点的沙漏**：科研永远在迭代，这里没有“结束”按钮，只有“投入”与“暂停”。
2. **🧠 元认知追踪**：不记录细碎的技术偏方，只记录你自身的效能、情绪、工具偏好与破局路径。
3. **🎯 注意力流向**：摒弃模糊的“阶段总计时”，精准追踪你在每一个具体工具（如 Audacity, Obsidian, 元宝Bot）上的专注时长。
4. **⚖️ 动态验收标准**：拒绝一刀切。根据“田野调查”、“语料库挖掘”或“理论思辨”的不同范式，动态呈现最严苛、最懂行的深水区验收指标。

## 🗺️ 语言学/人文学科专属 8 步 SOP

我们将庞杂的科研任务，像外科手术一样精准解剖为 8 个微关卡，并内置了极具实战意义的验收标准（Definition of Done）：

1. **灵感孵化与概念澄清**：概念提取、边界锚定、排除“死胡同”。
2. **文献检索与脉络梳理**：布尔运算、前向/后向追踪、构建图谱。
3. **文献阅读与综述撰写**：防范 AI 幻觉、原文追问、分类评述找 Gap。
4. **选题方向确定与可行性分析**：灵魂三问、3有2非原则、技术路线图。
5. **研究材料获取与元数据建库**：恪守“标准在先，建库在后”、录音环境控制、学术伦理。
6. **材料清洗、编码与数字化**：Audacity 克制降噪、OCR 清洗 3 大原则、隐私脱敏。
7. **报告撰写与逻辑打磨**：逻辑闭环、引文规范、导师反馈解码。
8. **答辩准备与模拟**：可视化 PPT、边际贡献提炼、Q\&A 防御题库。

## 📊 三位一体：科研效能体检报告

当您完成一个阶段的循环，点击生成报告，心语将为您呈现：

* **📊 A. 理性之镜 (数据洞察)**：通过 Chart.js 生成时间-心流四象限图表，寻找您的“效率密码”与“心流触发器”。
* **🛡️ B. 生存手册 (避坑指南)**：自动提取您记录的“卡点与破局”及“遗留的坑”，生成专属的避坑备忘录。
* **💌 C. 搭子之信 (情感陪伴)**：基于您的情绪曲线，写给您的一封时光回信，接纳您的疲惫，铭记您的专注。

## 🚀 快速开始

本项目为**纯前端单文件应用**，无需安装任何环境，无需配置服务器。

1. 克隆本仓库或直接下载 `index.html` 文件。
2. 双击使用现代浏览器（Chrome, Edge, Safari 等）打开。
3. 选择您的“研究范式”，点击“▶️ 计时”，开始您的科研心流之旅。
4. *(可选)* 点击“🖨️ 打印纸质通关地图”，将其贴在书桌前，享受用笔打勾的契约感。

## 🛡️ 隐私与安全承诺

科研数据与心智历程是极其私人的资产。
**心语星途 100% 纯本地运行**，所有数据（包括计时、情绪打分、复盘笔记）均加密存储在您的浏览器 `LocalStorage` 中。**没有任何数据会被上传至云端或用于 AI 训练。**
*(注：如需更换设备，请手动导出或截图保存您的“体检报告”。)*
